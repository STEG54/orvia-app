# Amaya

Logiciel de gestion pour agences d'animation, d'hôtesses et de merchandising : planning, contrats, paie, signatures, relevés terrain, exports.

Dépôt privé. Documentation technique : [LISEZMOI-DEV.md](LISEZMOI-DEV.md).

Les tests automatiques (onglet Actions) tournent à chaque modification.

Ne jamais déposer ici : config.php, clés S3, clé de signature des mises à jour, données d'agence.
